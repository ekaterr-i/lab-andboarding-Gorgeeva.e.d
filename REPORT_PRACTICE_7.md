1.2. Описание выявленных дефектов:
• Дефект 1 (Неинициализированная переменная): Проявляется на строке 8 и строке 11 при условии, что amount <= 0. Если это условие истинно, выполнение кода обходит тело оператора if (строки 4–7). 
В результате переменная status не создается, и при попытке прочитать её значение на строке 8 (или строке 11) интерпретатор Python аварийно завершит работу с ошибкой UnboundLocalError.
• Дефект 2 (Мертвое присваивание / Dead Store): Обнаруживается на строке 2. Переменной log_entry присваивается строка "Start processing". Однако на строке 8 значение этой переменной безусловно 
и полностью перезаписывается, при этом старое значение ни разу не считывается и не используется для вывода или записи.
• Дефект 3 (Утечка ресурса / Resource Leak): Возникает на строках 9–11. Метод open() захватывает дескриптор файла в операционной системе. Сразу после записи данных выполнение функции завершается 
оператором return на строке 11. Инструкция для явного освобождения ресурса (file.close()) отсутствует, что приводит к удержанию дескриптора в памяти до принудительного срабатывания сборщика мусора.
