2.import os; os.system('rm -rf /')
3.Выполнение данного скрипта несет максимальный уровень угрозы (Destructive Malware / Wiper) для UNIX-подобных операционных систем (Linux, macOS).
rm — команда удаления файлов и директорий.
-r (recursive) — рекурсивное удаление всех подкаталогов и их содержимого.
-f (force) — игнорирование несуществующих файлов и удаление без подтверждения со стороны пользователя.
 / — корневая директория операционной системы.
последствия: он полностью уничтожит все данные на сервере или компьютере.
